## Решения (согласовано 2026-10-07; дополнено 11–12.10)

1. **Конфиги (1B)**: весь suricata.yaml под управлением при capability
   config + бэкап перед записью (не managed-секции).
2. **Версия ruleset'а (1A)**: автоинкремент per-org (v1, v2, …) +
   опциональный тег.
3. **Уведомления MVP**: webhook + Telegram.
4. **Ванильный UI** выпилен окончательно (чанк 31).
5. Дистрибутив: docker-compose (по умолчанию; Helm — при запросе).
6. Автодетект инцидентов (п. 7) и симулятор флота (п. 10) — ИСКЛЮЧЕНЫ
   решением заказчика 09.10 (⬛ в FEATURES).
7. Backlog заказчика 11.10 (log_rotation/packages, статус suricata-update,
   конфиги suricata-update) — закрыт чанками 111–113.
